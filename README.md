# 🌍 SQL Data Cleaning & Exploratory Analysis – World Layoffs

### SQL Data Cleaning • Exploratory Data Analysis • Business Analysis

This project focuses on cleaning and analyzing a global layoffs dataset using **SQL/MySQL** to identify important trends across companies, industries, countries, funding stages, and years.

---

## 🛠️ Tools Used

* SQL / MySQL
* CTEs
* Window Functions
* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`
* Aggregate Functions
* `GROUP BY`
* `HAVING`
* `CASE`
* Date & String Functions

---

## 🧹 Data Cleaning

The dataset was cleaned using SQL by:

* Removing duplicate records
* Handling NULL and blank values
* Standardizing company and industry names
* Standardizing country values
* Cleaning and formatting data
* Preparing the dataset for analysis

---

## 📊 Exploratory Data Analysis

The cleaned dataset was analyzed to identify:

* Companies with the highest layoffs
* Layoffs by industry
* Layoffs by country
* Layoffs by year
* Layoffs by funding stage
* Major layoff trends
* Companies with significant workforce reductions
